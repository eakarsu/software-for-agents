# AI workspaces

AI Studio is visible in the authenticated application navigation. Its native `/api/runtime-ai/agent-readiness` request takes one `prompt` field (1–4000 characters). Three examples fill this complete input without calling a provider. Generate uses the configured canonical OpenRouter endpoint and returns the actual saved provider receipt; missing configuration and provider failure return real errors.

Cancel stops the browser request, the startup proxy's upstream request and actual provider transport. A cancellation or revoked identity before transaction completion rolls back the advisory receipt. Saved reports are scoped to the current authenticated account. Clicking a report opens a centered review with readable Copy/Download. Edit loads its original brief for a new request. Delete is unavailable because this native API has no destructive receipt contract.

The primary operational workflows, native roles, approval decisions and unavailable legacy endpoints retain their existing boundaries. Examples describe explicitly incomplete hypothetical review scopes and do not supply fictional saved records.

Agent workflow remains a separate source-grounded workflow: its three examples fill the question and optional latency/cost budgets. They preserve the manual action-authorization checkbox. One explicit Generate uses the native idempotent request and supports Cancel. Saved runs are scoped to the native actor and tenant; source citations, budgets, source freshness, schema checks and independent human action approvals remain required.
